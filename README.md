# Portfolio Website

A modern, responsive portfolio website showcasing photography and project work. Built with React and deployed on Cloudflare Workers.

## Features

- 🌍 **Multi-language Support** - English/Polish language switching
- 📸 **Photography Gallery** - Showcase your best work with optimized images
- 🎨 **Project Showcase** - Detailed project pages with portfolio-specific layouts
- 📧 **Contact Form** - Email integration using Resend for inquiries
- 🎭 **Smooth Animations** - Enhanced UX with Motion library animations
- 📱 **Responsive Design** - Mobile-first approach with adaptive layouts
- ⚡ **Fast Performance** - Built with Vite for optimized build times

## Tech Stack

- **Frontend**: React 19, React Router 7
- **Build Tool**: Vite
- **Styling**: CSS Modules, React Bootstrap
- **Hosting**: Cloudflare Workers
- **Email Service**: Resend
- **Animations**: Motion
- **Development**: ESLint, Prettier
